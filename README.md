# Calculator Frontend

A simple Calculator Frontend created using HTML and CSS.

## Features

- Clean and modern calculator UI
- Responsive design
- Number buttons
- Operator buttons
- Display screen

## Technologies Used

- HTML5
- CSS3

## Project Structure

```
calculator/
│── index.html
│── style.css
└── README.md
```

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser or run it using Live Server in VS Code.
